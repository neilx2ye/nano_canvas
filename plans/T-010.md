## Context

InfiniteCanvas 是整个应用的核心可视化组件，负责：
1. 初始化 Fabric.js 实例
2. 渲染所有 CanvasNode 图片节点
3. 处理画布缩放/平移/选中/删除操作
4. 与 CanvasContext 双向同步

此任务属于 Epic E-3（UI 组件）。

## Prerequisites

- ARCHITECTURE.md 第 6.1 节（InfiniteCanvas 职责）、第 6.2 节（CanvasNode 职责）、第 7.3 节（画布操作）
- T-005 的产出文件（CanvasContext 已实现）
- T-007 的产出文件（通用组件已实现）

## Steps

### Part A: InfiniteCanvas

1. 创建 `src/components/Canvas/InfiniteCanvas.tsx`
2. 使用 `useRef<HTMLCanvasElement>` 获取 canvas 元素引用
3. 使用 `useEffect` 初始化 Fabric.js：
   ```typescript
   const canvas = new fabric.Canvas(canvasRef.current, {
     width: window.innerWidth,
     height: window.innerHeight,
     backgroundColor: '#f5f5f5'
   });
   ```
4. 监听窗口 resize，动态调整 canvas 尺寸
5. 使用 `useCanvasContext` 获取 `nodes` 和 `selectedNodeId`
6. 使用 `useEffect` 同步 nodes 到 Fabric.js：
   - 遍历 `nodes`，查找已存在的 Fabric Image 对象
   - 不存在的节点：创建新的 `fabric.Image` 对象，设置 position、scale、rotation
   - 已存在的节点：根据 id 匹配后更新属性
   - 使用 `canvas.renderAll()` 刷新视图
7. 处理画布缩放：
   - 鼠标滚轮缩放：监听 `mouse:wheel` 事件
   - 缩放范围：0.1x ~ 5x
8. 处理画布平移：
   - 空格键 + 拖拽 或 鼠标中键拖拽
   - 监听 `mouse:down`、`mouse:move`、`mouse:up` 事件
9. 处理节点选中：
   - 监听 `selection:created`、`selection:updated` 事件
   - 调用 `selectNode` 更新 Context
   - 监听 `selection:cleared` 事件
   - 调用 `selectNode(null)` 清空选中
10. 清理 Effect：组件卸载时调用 `canvas.dispose()`
11. 返回 canvas 容器 div（ref 绑定 canvas 元素）

### Part B: CanvasNode（渲染逻辑，非独立组件）

12. 在 InfiniteCanvas 内部实现节点渲染逻辑（不单独拆分组件）
13. 每个节点是 `fabric.Image` 对象：
    - `id` 属性：存储节点 UUID
    - `left`、`top`：位置
    - `scaleX`、`scaleY`：缩放
    - `angle`：旋转
    - 可选中（`selectable: true`）
    - 可拖拽（`hasControls: true`）

### Part C: CanvasToolbar

14. 创建 `src/components/Canvas/CanvasToolbar.tsx`
15. 使用 `useCanvasContext` 获取 `selectedNodeId` 和 `removeNode`
16. 渲染工具栏按钮：
    - 删除选中节点（DeleteSelected）
    - 下载选中节点图片（DownloadSelected）
    - 清空画布（ClearAll）—— 需二次确认
17. 使用 `downloadNodeImage`（来自 src/utils/imageUtils.ts）实现下载
18. 使用 `useEffect` 监听键盘 Delete 键，触发删除选中节点
19. 样式：固定在画布左上角，半透明背景

### Part D: 统一导出

20. 创建 `src/components/Canvas/index.ts`，导出所有 Canvas 组件
