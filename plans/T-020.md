## Context
图片串联通过画布上的连接线实现。

## Prerequisites
- T-015 CanvasContext 的 connectNodes/disconnectNodes
- InfiniteCanvas 已有节点渲染逻辑

## Steps
1. 新建 CanvasConnection 组件：
   - 基于 Fabric.js Line 或 Path
   - 起点/终点绑定到 CanvasNode 中心
   - 样式：虚线箭头或实线带箭头
2. 修改 InfiniteCanvas：
   - 添加连接模式（从工具栏选择）
   - 模式下点击图片 A，再点击图片 B，建立连接
   - 调用 CanvasContext.connectNodes(fromId, toId)
   - 渲染时查询 node 的 connectedTo，绘制对应线条
3. 连接线跟随节点移动：节点 position 变化时更新线条端点
4. 支持删除连接线

## Acceptance
- 可创建/删除连接线
- 连接线正确绑定到节点中心
- 连接线跟随节点移动

## Out of Scope
- Prompt 构建逻辑（T-021）

## Examples
连接线使用 CanvasLine 或自定义 Path，存储在 fabricObjects 中。
