## Context

项目的数据模型是整个应用的数据契约。CanvasNode、GenerationConfig、TokenUsage 等接口必须在任何业务代码之前定义，确保所有模块之间的数据一致性。

此任务属于 Epic E-1（基础设施），为所有后续 UI 和业务逻辑提供类型基础。

## Prerequisites

- ARCHITECTURE.md 第 4 节（数据模型）
- T-001 的产出文件（package.json, src/ 基础结构已存在）

## Steps

1. 创建 `src/types/` 目录
2. 创建 `src/types/models.ts`，定义以下接口（严格按 ARCHITECTURE.md 第 4 节）：
   - `CanvasNode`：id（UUID）、imageData（base64）、position（{x,y}）、scale（number）、rotation（number）、createdAt（Date）、prompt（string）、model（string）、tokenUsed（number）
   - `GenerationConfig`：model（三种可选）、prompt、negativePrompt（可选）、steps（可选）、cfgScale（可选）、width、height、seed（可选）、refImage（可选，base64）、refImageStrength（可选）
   - `TokenUsage`：current（number）、total（number）
   - `InpaintRequest`：originalImageData（base64）、maskData（base64）、prompt、model、width、height，继承 GenerationConfig 的其他可选参数
3. 创建 `src/types/api.ts`，定义 API 请求/响应类型：
   - `GenerateRequest`：对应 API 请求体字段
   - `GenerateResponse`：包含 image（base64）、seed、token_used、processing_time_ms
   - `InpaintRequestBody`：对应局部重绘请求体
   - `ApiError`：包含 error.code（string）、error.message（string）
4. 从 `src/types/models.ts` 导出所有类型
5. 从 `src/types/api.ts` 导出所有类型
6. 创建 `src/types/index.ts`，统一导出：
   ```typescript
   export * from './models';
   export * from './api';
   ```

## Acceptance

- [ ] `CanvasNode` 接口包含所有必需字段且类型正确
- [ ] `GenerationConfig` 接口的 model 字段限定为三种模型
- [ ] `TokenUsage` 接口的 current 和 total 字段类型为 number
- [ ] `InpaintRequest` 接口包含 originalImageData、maskData、prompt 三个核心字段
- [ ] `GenerateResponse` 接口包含 image、seed、token_used 字段
- [ ] `ApiError` 接口符合统一错误格式
- [ ] TypeScript 编译无报错（运行 `pnpm tsc --noEmit`）
