## Context
用户可以对画布上的图片进行重新生成，保留历史版本。

## Prerequisites
- T-017 参数控件完成
- T-018 菜单交互完成
- T-016 API 方法可用

## Steps
1. 扩展 ImageNodeMenu：
   - 添加子菜单：模型选择 + Prompt 输入
   - 调用 API 时传入模型和 Prompt
2. 修改 CanvasContext：
   - 重新生成时：原图版本存入 versions，新图替换 imageData，isDefaultVisible=true
3. 修改 PromptInput：
   - 复用 generateImage 逻辑，但传入坐标参数在当前节点位置生成
   - 完成后更新 CanvasContext 的 nodes
4. 处理版本切换：点击版本列表时更新 imageData + isDefaultVisible

## Acceptance
- 重新生成流程完整：选择模型 → 输入 Prompt → 生成 → 版本保留
- 版本列表可切换

## Out of Scope
- 连接线渲染
- 串联 prompt 构建（T-020）

## Examples
