## Context
不同模型的参数支持不同，UI 需要动态调整可用性。

## Prerequisites
- T-014 类型定义扩展
- ARCHITECTURE.md 章节 2 技术栈

## Steps
1. 修改 ModelSelector，根据当前模型添加提示信息
2. 修改 ParamControls：
   - 禁用 nano-banana-pro 的 steps、cfgScale、seed（Gemini 不支持）
   - 禁用 nano-banana 的 imageSize
   - nano-banana-2 显示 thinking_level 选择器
3. 修改 ImageSizeSelector：
   - nano-banana: 仅 aspectRatio 选择
   - nano-banana-pro: 1K/2K/4K
   - nano-banana-2: 512/1K/2K/4K + 额外比例 1:4, 4:1, 1:8, 8:1
4. 参数联动：选择 Mask 模式时自动禁用 thinking_mode

## Acceptance
- 各模型的参数 UI 符合差异矩阵
- 参数联动正确（Mask ↔ thinking）

## Out of Scope
- 画布交互
- Prompt 构建

## Examples
ParamControls 中根据 model 控制禁用状态：
```typescript
const isPro = config.model === 'nano-banana-pro';
// steps, cfgScale, seed disabled when isPro
```
