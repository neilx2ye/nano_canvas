## Context
用户可以通过 Mask 模式进行局部抠图，仅 nano-banana 模型支持。

## Prerequisites
- T-017 参数控件完成（Mask 选项仅 nano-banana 可用）
- T-018 图片节点交互完成
- T-016 maskImage API 方法

## Steps
1. 修改 CanvasToolbar：
   - 选中图片时 + 模型为 nano-banana 时，显示 "Mask 模式" 按钮
   - 点击切换到 SketchOverlay
2. 修改 SketchOverlay：
   - 添加 mask 模式标识
   - 绘制完成后显示 "应用抠图" 按钮
   - 调用 maskImage(originalImage, maskData, prompt, model, width, height)
   - 成功后替换图片，保留版本
3. 处理 Mask 抠图的 prompt：用户输入抠图描述

## Acceptance
- Mask 按钮仅 nano-banana 显示
- 抠图流程完整（绘制 → 输入 prompt → 生成 → 版本保留）

## Out of Scope
- 通用涂鸦微调（已有 SketchPromptInput）

SketchOverlay 在 mask 模式下显示半透明覆盖层。
