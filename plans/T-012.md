## Context

API Key 是调用 Nano Banana API 的凭证。用户需要能够输入、保存和管理自己的 API Key。由于是本地工具，Key 存储在 localStorage 中。

此任务属于 Epic E-3（UI 组件）。

## Prerequisites

- ARCHITECTURE.md 第 3 节（目录结构中 Settings/ 部分）
- T-007 的产出文件（通用组件已实现）
- T-003 的产出文件（nanoBananaApi.ts 已实现 getApiKey/setApiKey/hasApiKey）

## Steps

1. 创建 `src/components/Settings/` 目录
2. 创建 `src/components/Settings/ApiKeyConfig.tsx`
3. 使用 `getApiKey`、`setApiKey`、`hasApiKey`（来自 src/services/nanoBananaApi.ts）
4. 组件逻辑：
   - 首次加载时检查是否有已保存的 API Key（`hasApiKey()`）
   - 若有，从 `getApiKey()` 获取并显示（部分隐藏，如 `sk_****xxxx`）
   - 若无，显示"请配置 API Key"提示
5. 实现输入表单：
   - `<input type="password">` 用于输入 Key
   - "保存"按钮：调用 `setApiKey(inputValue)`
   - "删除"按钮（仅在已有 Key 时显示）：调用 `removeApiKey()`
6. 保存/删除成功后显示成功提示（可使用简单的 alert 或内联提示）
7. 样式：简洁的卡片形式，可放在设置面板或侧边栏

### Part B: API Key 检测

8. 在 PromptInput 组件（来自 T-009）加载时检测 API Key 是否存在
9. 若不存在，PromptInput 的"生成"按钮禁用，并显示提示"请先配置 API Key"

### Part C: 统一导出

10. 创建 `src/components/Settings/index.ts`，导出所有设置组件

## Acceptance

- [ ] ApiKeyConfig 显示已保存的 API Key（部分隐藏）
- [ ] 可输入新 API Key 并保存
- [ ] 可删除已保存的 API Key
- [ ] PromptInput 检测到无 API Key 时禁用生成按钮
- [ ] 所有组件 TypeScript 编译无报错

## Out of Scope

- 不实现 API Key 有效性验证（调用 API 失败时提示）
- 不实现 API Key 加密存储（仅 localStorage）
- 不实现多 API Key 切换

## Examples

```tsx
<ApiKeyConfig />

// 在 PromptInput 中检测
const apiKeyExists = hasApiKey();
return (
  <Button disabled={!apiKeyExists}>
    {apiKeyExists ? '生成图片' : '请先配置 API Key'}
  </Button>
);
```
