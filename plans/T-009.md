## Context

Prompt 输入和参考图上传是用户发起 AI 生图的核心入口。PromptInput 负责收集用户描述，RefImageUpload 负责处理参考图上传和预览。

此任务属于 Epic E-3（UI 组件）。

## Prerequisites

- ARCHITECTURE.md 第 6.6 节（PromptInput 职责）、第 6.7 节（RefImageUpload 职责）
- T-007、T-008 的产出文件（通用组件、控制面板已实现）

## Steps

### Part A: RefImageUpload

1. 创建 `src/components/Prompt/RefImageUpload.tsx`
2. 使用 `useConfigContext` 获取 `config.refImage` 和 `updateConfig`
3. 实现参考图上传：
   - 文件选择：`<input type="file" accept="image/png,image/jpeg,image/webp">`
   - 使用 `validateImageFile` 验证文件（来自 src/utils/imageUtils.ts）
   - 验证通过后使用 `fileToBase64` 转换为 base64
   - 调用 `updateConfig({ refImage: base64Data })`
4. 实现预览：
   - 如果 `config.refImage` 存在，显示缩略图（max-width: 120px）
   - 提供"移除"按钮，点击调用 `updateConfig({ refImage: undefined })`
5. 错误处理：
   - 验证失败时显示红色错误提示文字
6. 样式：
   - 上传区域：虚线边框、点击触发文件选择
   - 预览区域：图片 + 移除按钮叠加显示

### Part B: PromptInput

7. 创建 `src/components/Prompt/PromptInput.tsx`
8. 使用 `useConfigContext` 获取 `config.prompt` 和 `updateConfig`
9. 使用 `useCanvasContext` 获取 `addNode`（用于生成成功后添加节点）
10. 使用 `useTokenContext` 获取 `recordUsage`（用于记录 Token）
11. 实现 Prompt 输入：
    - `<textarea>` 组件，多行文本输入
    - 高度：至少 3 行，可自动扩展
    - 占位符：`"描述你想生成的画面..."`
    - 双向绑定：`onChange` 时更新 `config.prompt`
12. 实现"生成"按钮：
    - 调用 `generateImage`（来自 src/services/nanoBananaApi.ts）
    - 使用 `config` 构建请求参数
    - 生成中显示 `loading` 状态
    - 生成成功后：
      - 创建新的 `CanvasNode`
      - 调用 `addNode` 添加到画布
      - 调用 `recordUsage` 记录 Token
    - 捕获 API 错误，显示错误 Toast
13. 实现快捷键：
    - Ctrl+Enter / Cmd+Enter 触发生成
14. 渲染 RefImageUpload 组件（在 PromptInput 下方）

### Part C: 统一导出

15. 创建 `src/components/Prompt/index.ts`，导出所有 Prompt 组件
