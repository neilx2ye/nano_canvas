## Context

控制面板是用户与 AI 生图交互的入口。用户通过这些组件选择模型、配置参数、选择尺寸、查看 Token 消耗。

此任务属于 Epic E-3（UI 组件）。

## Prerequisites

- ARCHITECTURE.md 第 6 节（组件职责边界）
- T-007 的产出文件（通用组件已实现）

## Steps

### Part A: ModelSelector

1. 创建 `src/components/Controls/ModelSelector.tsx`
2. 使用 `useConfigContext` 获取 config 和 updateConfig
3. 渲染三个横向单选按钮：
   - "Nano Banana" → value: 'nano-banana'
   - "Nano Banana 2" → value: 'nano-banana-2'
   - "Nano Banana Pro" → value: 'nano-banana-pro'
4. 当前选中项高亮显示（不同的背景色/边框）
5. 点击时调用 `updateConfig({ model: ... })`

### Part B: ImageSizeSelector

6. 创建 `src/components/Controls/ImageSizeSelector.tsx`
7. 使用 `useConfigContext`
8. 渲染预设尺寸快捷按钮（横向排列）：
   - 512×512
   - 768×768
   - 1024×1024
   - 1024×768
   - 768×1024
9. 选中预设时同时更新 width 和 height
10. 提供自定义输入：两个数字输入框（宽、高），允许用户自行输入
11. 当用户在自定义输入框输入时，清除预设选中状态

### Part C: ParamControls

12. 创建 `src/components/Controls/ParamControls.tsx`
13. 使用 `useConfigContext`
14. 使用 `Slider` 组件渲染以下参数：
    - Steps（1-100，步进1，默认25）
    - CFG Scale（1-20，步进0.5，默认7.0）
    - Seed（数值输入，默认空，表示随机）
    - Reference Image Strength（0-1，步进0.1，默认0.7）
15. 提供 Negative Prompt 文本输入框
16. 每个参数旁显示当前值

### Part D: TokenDisplay

17. 创建 `src/components/Controls/TokenDisplay.tsx`
18. 使用 `useTokenContext`
19. 使用 `useConfigContext` 获取当前配置中的模型信息（用于显示）
20. 渲染 Token 消耗信息：
    - 本次 Token 消耗（大字号显示）
    - 累计 Token 消耗（小字号）
    - 当前使用模型名称
21. 样式：固定在界面底部或侧边栏，浅色背景卡片
22. 使用 `formatTokenCount` 格式化数字（从 src/utils/index.ts 导入）

### Part E: 统一导出

23. 创建 `src/components/Controls/index.ts`，导出所有控制面板组件

## Acceptance
