## Context

CanvasContext 是画布节点状态的唯一数据源。所有组件（InfiniteCanvas、CanvasNode、控制面板等）都通过此 Context 读写节点数据。

此任务属于 Epic E-2（核心业务逻辑）。

## Prerequisites

- ARCHITECTURE.md 第 8.1 节（CanvasContext 接口设计）
- T-002 的产出文件（`src/types/index.ts` 已定义 `CanvasNode`）

## Steps

1. 创建 `src/contexts/` 目录
2. 创建 `src/contexts/CanvasContext.tsx`
3. 定义 `CanvasContextValue` 接口（严格按 ARCHITECTURE.md）：
   ```typescript
   interface CanvasContextValue {
     nodes: CanvasNode[];
     selectedNodeId: string | null;
     addNode: (node: CanvasNode) => void;
     updateNode: (id: string, updates: Partial<CanvasNode>) => void;
     removeNode: (id: string) => void;
     selectNode: (id: string | null) => void;
   }
   ```
4. 使用 `React.createContext<CanvasContextValue | null>(null)` 创建 Context
5. 使用 `useReducer` 管理 state：
   - State 初始值：`{ nodes: [], selectedNodeId: null }`
   - Reducer actions：`ADD_NODE`、`UPDATE_NODE`、`REMOVE_NODE`、`SELECT_NODE`
6. 实现 Reducer：
   - `ADD_NODE`：将新节点追加到 nodes 数组，设置 `selectedNodeId` 为新节点 id
   - `UPDATE_NODE`：遍历 nodes，找到 id 匹配的节点合并 updates
   - `REMOVE_NODE`：过滤掉 id 匹配的节点，若删除的是选中节点则 `selectedNodeId` 设为 null
   - `SELECT_NODE`：直接设置 `selectedNodeId`
7. 实现 Provider 组件：
   - Props：`{ children: React.ReactNode }`
   - 使用 `useMemo` 包裹 `contextValue`，依赖 `[state.nodes, state.selectedNodeId]`
   - 返回 `<CanvasContext.Provider value={contextValue}>`
8. 导出：
   - `CanvasContext`
   - `CanvasProvider`
   - `useCanvasContext` hook（内部调用 `useContext(CanvasContext)`，若 context 为 null 则 throw Error）

## Acceptance

- [ ] `addNode` 添加节点后自动选中新节点
- [ ] `updateNode` 正确合并部分更新
- [ ] `removeNode` 删除选中节点后清空选中状态
- [ ] `selectNode(null)` 可清空选中
- [ ] `useCanvasContext` 在 Context 外调用时抛出明确错误
- [ ] `contextValue` 使用 `useMemo` 避免不必要的重渲染
- [ ] TypeScript 编译无报错

## Out of Scope

- 不实现节点分组
- 不实现节点复制
- 不实现批量删除
- 不实现画布缩放/平移状态（这些由 Fabric.js 内部管理，不存入 Context）
- 不实现历史记录/撤销重做

## Examples

```tsx
// Provider 使用
<CanvasProvider>
  <App />
</CanvasProvider>

// Hook 使用
const { nodes, selectedNodeId, addNode, selectNode } = useCanvasContext();

// 添加节点
addNode({
  id: crypto.randomUUID(),
  imageData: 'data:image/png;base64,...',
  position: { x: 100, y: 100 },
  scale: 1.0,
  rotation: 0,
  createdAt: new Date(),
  prompt: 'a cat',
  model: 'nano-banana-2',
  tokenUsed: 850
});
```
