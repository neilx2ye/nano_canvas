## Context
CanvasContext 需要扩展以支持版本管理、图片串联查询。

## Prerequisites
- T-014 类型定义扩展

## Steps
1. 新增 `getVisibleNodes()` - 返回所有默认展示的节点
2. 新增 `getNodeVersions(nodeId)` - 返回指定节点的历史版本
3. 新增 `updateNodeVersion(nodeId, versionId)` - 切换默认展示版本
4. 新增 `connectNodes(fromId, toId)` - 建立图片串联
5. 新增 `disconnectNodes(fromId, toId)` - 解除串联

## Acceptance
- 所有新方法已实现且类型安全
- 现有 API 不受影响

## Out of Scope

- Prompt 构建逻辑
