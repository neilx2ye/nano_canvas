## Context

工具函数层封装通用的图像处理和 Token 格式化逻辑，供后续所有模块复用。

此任务属于 Epic E-2（核心业务逻辑），为所有 UI 组件提供无副作用的纯函数工具。

## Prerequisites

- ARCHITECTURE.md 第 3 节（目录结构中 utils/ 部分）
- T-002 的产出文件（`src/types/index.ts` 已定义所有类型）

## Steps

1. 创建 `src/utils/` 目录
2. 创建 `src/utils/imageUtils.ts`，实现以下函数：

   **2.1 文件转 base64**
   - 函数 `fileToBase64(file: File): Promise<string>`
   - 使用 FileReader，读取完成后返回 `data:image/<mimeType>;base64,<data>` 格式字符串
   - mimeType 从 `file.type` 获取（image/png / image/jpeg）

   **2.2 Canvas 转 base64**
   - 函数 `canvasToBase64(canvas: HTMLCanvasElement, quality?: number): string`
   - 调用 `canvas.toDataURL('image/png', quality)`
   - quality 参数可选，默认为 1.0

   **2.3 验证图片文件**
   - 函数 `validateImageFile(file: File): { valid: boolean; error?: string }`
   - 允许类型：image/png、image/jpeg、image/webp
   - 最大大小：10MB（通过 `file.size` 检查，10MB = 10 * 1024 * 1024）
   - 返回 `{ valid: true }` 或 `{ valid: false, error: "..." }`

   **2.4 下载图片**
   - 函数 `downloadImage(base64Data: string, filename: string): void`
   - 创建临时 `<a>` 元素，设置 `href` 为 base64 数据
   - 设置 `download` 属性为 filename
   - 触发点击事件
   - 清理临时元素

   **2.5 下载画布节点图片**
   - 函数 `downloadNodeImage(imageData: string, prompt: string): void`
   - 从 prompt 提取前 20 个字符作为文件名（去除空格和特殊字符）
   - 文件名格式：`nano_canvas_<timestamp>_<prompt_prefix>.png`

3. 创建 `src/utils/tokenUtils.ts`，实现以下函数：

   **3.1 格式化 Token 数量**
   - 函数 `formatTokenCount(tokens: number): string`
   - 小于 1000：直接返回数字字符串
   - 大于等于 1000：返回 `"1,234"` 格式（每 3 位加逗号）

   **3.2 解析 API 响应 Token**
   - 函数 `parseTokenUsage(response: GenerateResponse): number`
   - 返回 `response.token_used` 字段，默认为 0

4. 创建 `src/utils/index.ts`，统一导出：
   ```typescript
   export * from './imageUtils';
   export * from './tokenUtils';
   ```

## Acceptance

- [ ] `fileToBase64` 返回正确格式的 data URI
- [ ] `validateImageFile` 正确拒绝超过 10MB 的文件
- [ ] `validateImageFile` 正确拒绝非图片文件
- [ ] `downloadImage` 触发浏览器下载
- [ ] `formatTokenCount(850)` 返回 `"850"`
- [ ] `formatTokenCount(1234)` 返回 `"1,234"`
- [ ] TypeScript 编译无报错

## Out of Scope

- 不实现图片裁剪、缩放、旋转等图像处理
- 不实现图片上传到云端
- 不实现图片压缩（仅在下载时使用 canvas.toDataURL）
- 不实现 Token 持久化存储

## Examples

```typescript
// 文件验证
const result = validateImageFile(someFile);
if (!result.valid) {
  alert(result.error); // "图片大小不能超过 10MB"
}

// Token 格式化
formatTokenCount(850);    // "850"
formatTokenCount(1000);   // "1,000"
formatTokenCount(1234567); // "1,234,567"

// 下载图片
downloadImage(base64Data, 'my_image.png');
```
