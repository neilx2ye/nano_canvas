## Context

ConfigContext 管理生成配置（模型选择、参数、尺寸），TokenContext 管理 Token 消耗统计。两者均为全局状态，供各组件读取和修改。

此任务属于 Epic E-2（核心业务逻辑）。

## Prerequisites

- ARCHITECTURE.md 第 8.2 节（ConfigContext 接口）、第 8.3 节（TokenContext 接口）
- T-002 的产出文件（`src/types/index.ts` 已定义 `GenerationConfig`、`TokenUsage`）

## Steps

### Part A: ConfigContext

1. 创建 `src/contexts/ConfigContext.tsx`
2. 定义 `ConfigContextValue` 接口：
   ```typescript
   interface ConfigContextValue {
     config: GenerationConfig;
     updateConfig: (updates: Partial<GenerationConfig>) => void;
     resetConfig: () => void;
   }
   ```
3. 定义默认配置常量：
   ```typescript
   const DEFAULT_CONFIG: GenerationConfig = {
     model: 'nano-banana',
     prompt: '',
     negativePrompt: '',
     steps: 25,
     cfgScale: 7.0,
     width: 1024,
     height: 1024,
     seed: undefined,
     refImage: undefined,
     refImageStrength: 0.7
   };
   ```
4. 使用 `useReducer` 管理配置状态
5. 实现 `updateConfig`：合并 partial 更新到当前配置
6. 实现 `resetConfig`：恢复为 `DEFAULT_CONFIG`
7. 导出 `ConfigContext`、`ConfigProvider`、`useConfigContext`

### Part B: TokenContext

1. 创建 `src/contexts/TokenContext.tsx`
2. 定义 `TokenContextValue` 接口：
   ```typescript
   interface TokenContextValue {
     usage: TokenUsage;
     recordUsage: (tokens: number) => void;
     resetTotal: () => void;
   }
   ```
3. 初始值：`{ current: 0, total: 0 }`
4. 实现 `recordUsage`：更新 `current` 为传入值，`total` 累加传入值
5. 实现 `resetTotal`：将 `total` 重置为 0
6. 导出 `TokenContext`、`TokenProvider`、`useTokenContext`

### Part C: 统一导出

7. 创建 `src/contexts/index.ts`：
   ```typescript
   export { CanvasProvider, useCanvasContext } from './CanvasContext';
   export { ConfigProvider, useConfigContext } from './ConfigContext';
   export { TokenProvider, useTokenContext } from './TokenContext';
   export { CanvasContext } from './CanvasContext';
   export { ConfigContext } from './ConfigContext';
   export { TokenContext } from './TokenContext';
   ```

## Acceptance

- [ ] `ConfigContext` 默认模型为 `nano-banana`
- [ ] `updateConfig({ model: 'nano-banana-pro' })` 正确更新
- [ ] `resetConfig()` 恢复所有字段为默认值
- [ ] `TokenContext` 首次 `recordUsage(850)` 后：`current=850, total=850`
- [ ] 第二次 `recordUsage(720)` 后：`current=720, total=1570`
- [ ] `resetTotal()` 将 total 归零但 current 不变
- [ ] `useConfigContext` / `useTokenContext` 在 Context 外调用时抛出明确错误
- [ ] TypeScript 编译无报错

## Out of Scope

- 不实现 Token 持久化到 localStorage（仅内存）
- 不实现 Token 配额警告
- 不实现配置持久化

## Examples

```tsx
// Config 使用
const { config, updateConfig } = useConfigContext();
updateConfig({ width: 768, height: 768 });

// Token 使用
const { usage, recordUsage } = useTokenContext();
// API 返回后
recordUsage(response.token_used);
// 显示
console.log(`本次消耗: ${usage.current}, 累计: ${usage.total}`);
```
