## Context

项目起点。需要在 `E:\nano_canvas` 目录下初始化一个完整可运行的 Vite + React + TypeScript + Tailwind CSS + Fabric.js 项目。

这是所有后续任务的基础，worker 必须确保安装正确版本的依赖，并配置好 TypeScript、Tailwind、Vite 的基础配置。

## Prerequisites

- ARCHITECTURE.md 第 2 节（技术栈）
- ARCHITECTURE.md 第 3 节（目录结构）

## Steps

1. 在 `E:\nano_canvas` 目录下执行 `pnpm create vite@latest . --template react-ts`，覆盖已有文件（已确认 ARCHITECTURE.md）
2. 安装依赖：
   ```
   pnpm add fabric@6
   pnpm add -D tailwindcss postcss autoprefixer @types/fabric
   ```
3. 初始化 Tailwind：
   ```
   npx tailwindcss init -p
   ```
4. 配置 `tailwind.config.js`：在 `content` 数组中添加 `./index.html` 和 `./src/**/*.{ts,tsx}`
5. 配置 `vite.config.ts`：确认 HMR 配置正常
6. 在 `src/index.css` 顶部添加 Tailwind 指令：
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```
7. 确认 `src/main.tsx` 渲染 `<App />`
8. 确认 `src/App.tsx` 渲染一个简单的 `<h1>Hello Nano Canvas</h1>`
9. 确认 `index.html` 中 `<title>` 为 `"Nano Canvas"`
10. 在 `package.json` 的 `scripts` 中添加 `"dev": "vite"` 确认无误
11. 运行 `pnpm dev`，确认浏览器可访问（http://localhost:5173）
