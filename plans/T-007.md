## Context

通用 UI 组件是项目中唯一使用 Tailwind CSS 的地方。所有业务组件（Controls、Canvas 等）都复用这些通用组件，确保视觉一致性。

此任务属于 Epic E-3（UI 组件）。

## Prerequisites

- ARCHITECTURE.md 第 2 节（技术栈：Tailwind CSS）
- T-001 的产出文件（Tailwind 已配置）

## Steps

1. 创建 `src/components/common/` 目录
2. 创建 `src/components/common/Button.tsx`：
   - Props：`variant`（'primary' | 'secondary' | 'danger'）、`size`（'sm' | 'md' | 'lg'）、`disabled`（boolean）、`loading`（boolean）、`onClick`、继承 `React.ButtonHTMLAttributes<HTMLButtonElement>`
   - 使用 Tailwind 样式：
     - primary：蓝底白字
     - secondary：灰边框灰底
     - danger：红底白字
     - sm：px-2 py-1 text-sm
     - md：px-4 py-2 text-base
     - lg：px-6 py-3 text-lg
   - `disabled` 时降低透明度、禁止点击
   - `loading` 时显示 Spinner 并禁止点击

3. 创建 `src/components/common/Select.tsx`：
   - Props：`label`（string）、`value`（string）、`options`（`{ value: string; label: string }[]`）、`onChange`（`(value: string) => void`）
   - 使用 Tailwind 的 `<select>` 原生元素
   - 样式：边框、圆角、内边距、背景色

4. 创建 `src/components/common/Slider.tsx`：
   - Props：`label`（string）、`value`（number）、`min`（number）、`max`（number）、`step`（number）、`onChange`（`(value: number) => void`）、`displayValue`（可选，显示格式化值）
   - 使用原生 `<input type="range">`
   - 样式：宽度 100%、标签在左侧、数值在右侧
   - `displayValue` 格式：例如 `steps: 25`

5. 创建 `src/components/common/Spinner.tsx`：
   - Props：`size`（'sm' | 'md' | 'lg'）
   - 使用 CSS 动画旋转的圆形 spinner
   - sm：16px，md：24px，lg：40px
   - 颜色：使用 currentColor（继承父元素颜色）

6. 创建 `src/components/common/index.ts`，统一导出所有组件

## Acceptance

- [ ] `Button` variant='primary' 显示蓝色背景
- [ ] `Button` loading=true 显示 Spinner 且禁用点击
- [ ] `Select` 渲染所有 options，可正常切换
- [ ] `Slider` 拖动时 onChange 被调用，value 更新
- [ ] `Slider` 显示 `displayValue`（如 "25 steps"）
- [ ] `Spinner` 持续旋转动画
- [ ] 所有组件 TypeScript 编译无报错

## Out of Scope

- 不实现复杂的表单验证
- 不实现自定义下拉菜单（仅原生 select）
- 不实现 Slider 的双滑块（范围选择）
- 不实现 Button 的图标支持

## Examples

```tsx
<Button variant="primary" onClick={handleGenerate}>
  生成图片
</Button>

<Select
  label="模型"
  value={config.model}
  options={[
    { value: 'nano-banana', label: 'Nano Banana' },
    { value: 'nano-banana-2', label: 'Nano Banana 2' },
    { value: 'nano-banana-pro', label: 'Nano Banana Pro' }
  ]}
  onChange={(v) => updateConfig({ model: v as any })}
/>

<Slider
  label="Steps"
  value={config.steps ? 25}
  min={1}
  max={100}
  step={1}
  displayValue={`${config.steps ? 25}`}
  onChange={(v) => updateConfig({ steps: v })}
/>
```
