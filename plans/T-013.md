## Context

MainPage 是应用的唯一页面，整合所有组件并定义整体布局。App.tsx 负责设置 Providers 和路由。

此任务是 Epic E-3（UI 组件）的收尾，也是整个项目集成的关键一步。

## Prerequisites

- ARCHITECTURE.md 第 3 节（目录结构中 pages/ 部分）
- T-005、T-006 的产出文件（所有 Context 已实现）
- T-008、T-009、T-010、T-011、T-012 的产出文件（所有 UI 组件已实现）

## Steps

### Part A: MainPage 布局

1. 创建 `src/pages/MainPage.tsx`
2. 布局结构：
   ```
   +------------------------------------------+
   |  顶部工具栏（Logo + 设置按钮）             |
   +--------------------+----------------------+
   |  左侧控制面板       |                      |
   |  - ApiKeyConfig    |    InfiniteCanvas   |
   |  - ModelSelector   |    (画布区域)        |
   |  - ImageSizeSelector|                     |
   |  - ParamControls   |                      |
   |  - TokenDisplay    |                      |
   |  - PromptInput     |                      |
   |  - RefImageUpload  |                      |
   +--------------------+----------------------+
   ```
3. 使用 Tailwind CSS 的 Flexbox/Grid 实现响应式布局：
   - 左侧面板：固定宽度（如 w-80），可滚动
   - 右侧画布：flex-1，占据剩余空间
4. 在画布区域的节点选中时，显示 Sketch 组件：
   - 使用 `useCanvasContext` 获取 `selectedNodeId`
   - 若存在选中节点，显示"微调"按钮（通过 CanvasToolbar 已有功能或独立按钮）
   - SketchOverlay 和 SketchPromptInput 作为条件渲染叠加在画布上方

### Part B: App.tsx 整合

5. 修改 `src/App.tsx`：
   - 引入 `CanvasProvider`、`ConfigProvider`、`TokenProvider`
   - 用三个 Provider 包裹 MainPage
   - 顺序：CanvasProvider → ConfigProvider → TokenProvider（CanvasProvider 在外层，因为其他 Context 可能需要读取 Canvas 状态）

### Part C: 样式完善

6. 在 `src/index.css` 添加全局样式：
   - 去除 body 默认 margin/padding
   - 设置 font-family
   - 设置 scrollbar 样式（美观）
7. 确认 Tailwind 的 `@tailwind` 指令在 `index.css` 顶部

### Part D: 响应式处理

8. MainPage 响应式断点：
   - `md` 及以上：左侧面板 + 右侧画布
   - `md` 以下（移动端）：Tab 切换（控制面板 / 画布）—— 简化实现，使用两个可切换面板

## Examples

```tsx
// App.tsx
function App() {
  return (
    <CanvasProvider>
      <ConfigProvider>
        <TokenProvider>
          <MainPage />
        </TokenProvider>
      </ConfigProvider>
    </CanvasProvider>
  );
}

// MainPage.tsx
function MainPage() {
  const { selectedNodeId } = useCanvasContext();
  
  return (
    <div className="flex h-screen">
      <aside className="w-80 overflow-y-auto border-r">
        <ApiKeyConfig />
        <ModelSelector />
        <ImageSizeSelector />
        <ParamControls />
        <TokenDisplay />
        <PromptInput />
        <RefImageUpload />
      </aside>
      <main className="flex-1 relative">
        <InfiniteCanvas />
        <CanvasToolbar />
        {selectedNodeId && (
          <>
            <SketchOverlay ... />
            <SketchPromptInput ... />
          </>
        )}
      </main>
    </div>
  );
}
```
