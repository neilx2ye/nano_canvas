## Context

涂鸦微调是本应用的核心差异化功能。用户选中画布上的图片节点后，通过涂鸦指定需要重绘的区域，配合文字描述实现局部微调。

此任务属于 Epic E-3（UI 组件）。

- ARCHITECTURE.md 第 7.2 节（涂鸦微调流程）

- T-007 的产出文件（通用组件已实现）

## Steps

### Part A: SketchOverlay

1. 创建 `src/components/Sketch/SketchOverlay.tsx`
2. Props：
   - `originalImageData: string` —— 原图 base64
   - `onComplete: (maskData: string) => void` —— 涂鸦完成回调，传递 mask base64
   - `onCancel: () => void` —— 取消回调
3. 使用 `useRef<HTMLCanvasElement>` 获取 canvas 元素
4. 初始化遮罩 canvas：
   - 尺寸与原图相同（或自适应父容器）
   - 背景：黑色半透明（rgba(0,0,0,0.7)）
   - 在其上叠加一层透明绘制层（用于用户涂鸦）
5. 实现涂鸦绘制：
   - 监听 `mousedown`、`mousemove`、`mouseup` 事件
   - 画笔颜色：白色（#ffffff）—— 作为 mask 标识重绘区域
   - 画笔粗细：可调（默认 20px），由外部 props 传入或内部 state 管理
   - 绘制时使用 `lineTo` 连接路径
6. 实现控制按钮：
   - "完成涂鸦"按钮：调用 `onComplete` 并传入 mask base64
   - "取消"按钮：调用 `onCancel`
   - "清除"按钮：清空绘制层，重新开始
7. 使用 canvas API 生成 mask base64：
   - 创建临时 canvas
   - 绘制纯白色（#ffffff）区域表示需要重绘的部分
   - 导出为 base64

### Part B: SketchPromptInput

8. 创建 `src/components/Sketch/SketchPromptInput.tsx`
9. Props：
   - `maskData: string` —— 涂鸦生成的 mask base64
   - `originalImageData: string` —— 原图 base64（用于显示）
   - `onSubmit: (prompt: string) => void` —— 提交回调
   - `onCancel: () => void` —— 取消回调
10. 渲染 Modal（居中显示，背景遮罩）
11. 在 Modal 内显示：
    - 原图预览（小图）
    - 涂鸦区域预览（mask 叠加显示）
    - Prompt 输入框（文本区域）
    - "发送"按钮
    - "取消"按钮
12. 实现提交逻辑：
    - 调用 `inpaintImage`（来自 src/services/nanoBananaApi.ts）
    - 传递 `original_image`、`mask`、`prompt`、`model`、尺寸
    - 成功时调用 `onSubmit(prompt)`
    - 显示 loading 状态
    - 捕获 API 错误，显示错误 Toast
13. 更新 CanvasContext：
    - 成功后将新图片数据更新到原节点（通过 `updateNode`）
    - 记录 Token 消耗（通过 `recordUsage`）

### Part C: 集成到画布节点

14. 在 CanvasNode 的选中状态上添加"微调"按钮
15. 点击"微调"：
    - 显示 SketchOverlay
    - 用户涂鸦完成后显示 SketchPromptInput
    - 完成后替换原节点图片

### Part D: 统一导出

16. 创建 `src/components/Sketch/index.ts`，导出所有 Sketch 组件

## Examples

```tsx
// 选中节点后触发
{selectedNode && (
  <SketchOverlay
    originalImageData={selectedNode.imageData}
    onComplete={(mask) => setMaskData(mask)}
    onCancel={() => setShowSketch(false)}
  />
)}

{maskData && (
  <SketchPromptInput
    maskData={maskData}
    originalImageData={selectedNode.imageData}
    onSubmit={(prompt) => handleInpaint(prompt)}
    onCancel={() => { setMaskData(null); }}
  />
)}
```
