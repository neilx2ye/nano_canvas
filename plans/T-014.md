## Context
本次迭代需要扩展数据模型以支持：图片标注、多版本管理、图片串联、Mask 抠图。

## Prerequisites
- ARCHITECTURE.md 第 4 节数据模型

## Steps
1. 扩展 `CanvasNode` 接口，新增字段：
   - `annotation?: string` - 用户对图片的标注
   - `versions?: CanvasNodeVersion[]` - 历史版本数组
   - `connectedFrom?: string` - 前置节点 ID
   - `connectedTo?: string[]` - 后继节点 ID 列表
   - `isDefaultVisible?: boolean` - 是否为默认展示版本
2. 新增 `CanvasNodeVersion` 接口
3. 扩展 `GenerateResponse`，新增 `thinkingSteps?: string[]`
4. 确保 `InpaintRequestBody` 包含 mask 参数

## Acceptance
- CanvasNode 新增字段通过 TypeScript 编译
- 现有使用 CanvasNode 的代码不报错

## Out of Scope
- 不实现具体业务逻辑
- 不修改 API 调用

## Examples
```typescript
interface CanvasNodeVersion {
  id: string;
  imageData: string;
  prompt: string;
  createdAt: Date;
}
```
