## Context

API 服务层是与 Nano Banana API 通信的唯一入口。后续所有 Hooks 和组件都通过此服务发起请求，因此必须：
1. 统一处理 API Key 配置（从 localStorage 读取）
2. 统一处理请求/响应格式
3. 统一处理错误结构
4. 提供类型安全的调用接口

此任务属于 Epic E-2（核心业务逻辑）。

## Prerequisites

- ARCHITECTURE.md 第 5 节（API 规范）
- T-002 的产出文件（`src/types/index.ts` 已定义所有类型）

## Steps

1. 创建 `src/services/` 目录
2. 创建 `src/services/nanoBananaApi.ts`
3. 实现以下函数：

   **3.1 API Key 管理**
   - 函数 `getApiKey(): string | null`：从 `localStorage.getItem('nano_api_key')` 读取
   - 函数 `setApiKey(key: string): void`：存入 `localStorage`
   - 函数 `removeApiKey(): void`：从 localStorage 删除
   - 函数 `hasApiKey(): boolean`：检查是否存在

   **3.2 生成图片 `generateImage(config: GenerateRequest): Promise<GenerateResponse>`**
   - URL: `POST /v1/generate`（注意：API URL 需通过环境变量或常量配置，基础路径存为 `API_BASE_URL` 常量，worker 需明确声明占位符值 `https://api.nanobanana.example`）
   - 请求头：`Authorization: Bearer <API_KEY>`
   - 发送完整的 `config` 对象作为 JSON body
   - 成功时返回 `GenerateResponse`
   - 失败时抛出 `ApiError`（解析响应体的 error 字段）

   **3.3 局部重绘 `inpaintImage(req: InpaintRequestBody): Promise<GenerateResponse>`**
   - URL: `POST /v1/inpaint`
   - 请求头同上
   - 发送包含 original_image、mask、prompt、model、width、height 的 body
   - 成功/失败处理同上

   **3.4 Token 提取**
   - 函数 `extractTokenUsed(response: GenerateResponse): number`：返回 response.token_used 字段值

   **3.5 错误处理**
   - 函数 `handleApiError(response: Response): Promise<never>`：将 HTTP 错误转换为结构化 `ApiError`
   - HTTP 4xx/5xx 均视为错误，抛出 `{ error: { code: string, message: string } }`

4. 在文件顶部声明常量：
   ```typescript
   const API_BASE_URL = 'https://api.nanobanana.example';
   ```
5. 导出所有函数：
   ```typescript
   export { getApiKey, setApiKey, removeApiKey, hasApiKey, generateImage, inpaintImage, extractTokenUsed };
   ```

## Acceptance

- [ ] `getApiKey` / `setApiKey` / `hasApiKey` 操作 localStorage 正确
- [ ] `generateImage` 发送正确格式的请求体
- [ ] `inpaintImage` 发送正确格式的请求体（包含 original_image、mask 字段）
- [ ] 成功响应时返回 `GenerateResponse` 类型
- [ ] HTTP 错误时抛出包含 `code` 和 `message` 的 `ApiError`
- [ ] TypeScript 编译无报错

## Out of Scope

- 不实现 UI（不返回 JSX）
- 不处理图片下载逻辑
- 不实现 Token 持久化（仅在 API 响应中提取）
- 不实现请求重试逻辑
- 不实现请求取消（AbortController）

## Examples

```typescript
// 生成图片调用
const response = await generateImage({
  model: 'nano-banana-2',
  prompt: 'a cute cat',
  width: 1024,
  height: 1024,
  steps: 25,
  cfg_scale: 7.0
});
console.log(response.token_used); // 850

// 局部重绘调用
const inpaintResponse = await inpaintImage({
  model: 'nano-banana-2',
  original_image: 'data:image/png;base64,...',
  mask: 'data:image/png;base64,...',
  prompt: 'change cat color to blue',
  width: 1024,
  height: 1024
});

// 错误处理
try {
  await generateImage({ ... });
} catch (err) {
  if (err.error?.code === 'INVALID_API_KEY') {
    // 提示用户配置 API Key
  }
}
```
