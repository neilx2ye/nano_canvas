## Context
API 层需要支持：
1. Thinking 模式：解析 Gemini 返回的 thinking 步骤
2. Mask 抠图：支持 mask 参数传递

## Prerequisites
- T-014 类型定义扩展
- gemini_image_models_spec.md 章节 2.2 请求骨架

## Steps
1. 新增 `generateWithThinking(config)` - 发送请求时带上 thinking 模式，返回 `{ image, thinkingSteps }`
2. 新增 `maskImage(originalImage, maskData, prompt, model, width, height)` - 调用 Mask 抠图 API
3. 解析 Gemini 响应中的 thinking 步骤（需查看 spec 中 thinking 输出格式）
4. 确保现有 `generateImage()` 函数签名不变

## Acceptance
- generateImage 保持向后兼容
- 新方法类型安全且错误处理完善

## Out of Scope
- UI 展示 thinking 步骤
- 参数联动逻辑

## Examples
```typescript
generateWithThinking(config: GenerateRequest): Promise<{ image: string; thinkingSteps: string[] }>;
```
